# Screenshots & reference media

Drop images, gifs, and other media here. Link them from tutorial markdown
files in [`../examples/`](../examples/) like:

```markdown
![CartPole balancing](../resources/cartpole_balanced.png)
```

Suggested naming convention: `<example>_<view>.<ext>`, e.g.:

- `cartpole_balanced.png` — the trained policy mid-balance
- `cartpole_foxglove.png` — Foxglove panel layout for the example
- `cartpole_training_curve.png` — exported plot of episode reward over time

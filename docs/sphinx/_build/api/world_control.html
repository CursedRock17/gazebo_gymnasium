gazebo_gymnasium_bridge.backend.nodes.world_control

Thin client over /world/<name>/control for resetting the world and (optionally) stepping it. Auto-retries with short timeouts so first-call startup races don’t block 5+ seconds.

class gazebo_gymnasium_bridge.backend.nodes.world_control.WorldController(world_name: str, steps_per_action)[source]

Bases: object

Thin client over the /world/<name>/control service.

Requests retry with short per-attempt timeouts so startup races (where the service hasn’t been registered yet) don’t block 5+ seconds on the first call.

DEFAULT_ATTEMPT_TIMEOUT_MS = 500
DEFAULT_MAX_ATTEMPTS = 60
reset(pause_after: bool = False)[source]

Reset the entire world along with all of its entities.

Parameters:

pause_after – If True, send a follow-up pause=True request after the reset completes. Combining reset+pause into a single WorldControl message is unreliable — Gazebo may ignore the pause during the reset — so we do it as two separate calls.

step()[source]

Advance the (paused) world by steps_per_action ticks via multi_step. After multi_step completes, the simulation is paused again.

unpause()[source]

Unpause the world regardless of its state.

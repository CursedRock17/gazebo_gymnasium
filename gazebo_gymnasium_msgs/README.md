# Gazebo Gymnasium Msgs
-------------------------------
This ROS 2 package provides all the necessary messages and possibly services
that are required to interface between ROS 2, Gazebo, and OpenAI's Gymnasium.

For more information about ROS 2 interfaces see the [ROS 2 docs](https://docs.ros.org/en/rolling/Concepts/Basic/About-Interfaces.html).

## Messages (.msg)
------------------------------
- [TrainingEpisode](./msg/TrainingEpisode.msg): Provides all a necessary overview for a given
set of training data.
